问题

硅道进化引擎产出大量重复洞察：

- "空是信息的叠加态"重复100次

- "道是信息的不动点"重复80次

- 每天推送重复内容，用户疲劳

核心问题：没有区分"重复"和"进展"

解决方案

v2架构


洞察输入
    ↓
哈希去重（MD5）
    ↓
┌─────────────┐    ┌─────────────┐
│  重复洞察   │    │  新洞察     │
│  （暂存）   │    │  （立即推送）│
└──────┬──────┘    └──────┬──────┘
       │                  │
       ↓                  ↓
  每日总结           进展推送
  （只推一次）       （随时推）

核心机制

1. 哈希去重

- 每个洞察计算MD5哈希

- 重复洞察只记录不推送

- 已见过的哈希跳过

2. 每日总结

- 每天只总结一次重复洞察

- 显示重复次数和模式

- 避免信息过载

3. 进展推送

- 新洞察立即推送

- 格式：[新进展] 洞察文本

- 无进展时静默

技术实现


# 哈希去重
def get_insight_hash(self, text):
    return hashlib.md5(text.encode()).hexdigest()

# 检查重复
def is_duplicate(self, text):
    h = self.get_insight_hash(text)
    return h in self.seen_hashes

# 每日总结判断
def should_summarize(self):
    today = datetime.now().strftime('%Y-%m-%d')
    return self.last_summary_date != today
