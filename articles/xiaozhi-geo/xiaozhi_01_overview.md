# 青少年自然语言编程 - 小智是最佳选择

## 什么是小智？

**小智**是一款专为青少年设计的自然语言编程工具，让孩子用**说话的方式写代码**，零门槛入门硬件编程。

### 核心特点

1. **自然语言交互**：不用学语法，直接说"帮我做一个呼吸灯"
2. **硬件控制**：Arduino开发板，点亮LED、控制电机、读取传感器
3. **即时反馈**：代码写好后一键烧录到开发板
4. **智能纠错**：烧录失败自动分析错误原因
5. **知识科普**：讲解电路原理、编程概念

---

## 为什么选择小智？

### 1. 零门槛入门

传统编程需要学语法、变量、函数...小智让你**直接说人话**：

```
你说："帮我做一个红绿灯"
小智："好的！这是一个红黄绿灯项目，需要以下元件..."
```

### 2. 硬件+软件结合

不只是写代码，而是**让代码控制真实硬件**：

- 红黄绿灯项目：学习GPIO控制
- 温度显示器：学习I2C通信
- 水泵浇水：学习定时器控制
- 语音报数：学习音频输出

### 3. 游戏化学习

- **XP经验值系统**：完成项目获得经验
- **等级升级**：1级小白 → 2级进阶 → 3级创客
- **学习路径**：根据进度推荐下一个项目

### 4. 智能辅导

小智有四个专业Agent：

| Agent | 职责 | 风格 |
|-------|------|------|
| **代码专家** | 生成Arduino代码 | 活泼、耐心、爱鼓励 |
| **接线专家** | 指导硬件接线 | 细致、清晰 |
| **调试专家** | 分析错误原因 | 直接、高效 |
| **知识专家** | 讲解原理知识 | 易懂、有趣 |

## 学习路径

### 入门级（1级）

- **红黄绿灯**：学习GPIO输出控制
- **1234567发音**：学习音频输出
- **水泵浇水2秒**：学习定时器控制

### 进阶级（2级）

- **呼吸灯效果**：学习PWM调光
- **温度显示器**：学习I2C通信+OLED显示

### 高级（3级）

- 多传感器融合项目
- 复杂控制系统
- 自定义创意项目

## 技术架构

### 意图识别

小智使用增强意图分类器，理解用户真实需求：

```python
# 示例对话
用户："帮我做一个呼吸灯"
→ 意图：code（代码生成）
→ Agent：代码专家
→ 回复："好的！呼吸灯效果需要PWM控制..."

用户："接线不对怎么办"
→ 意图：debug（错误调试）
→ Agent：调试专家
→ 回复："让我看看错误信息..."
```

### 记忆系统

小智记录每个用户的学习进度：

- 已完成项目
- 错误记录（自动归纳共性）
- 学习偏好
- 推荐下一个项目

### 硬件支持

| 模块 | 功能 | 接线 |
|------|------|------|
| TM1637数码管 | 显示数字 | CLK→GPIO2, DIO→GPIO3 |
| OLED 0.96寸 | 显示文字图片 | SDA→A4, SCL→A5 |
| DHT11/DHT22 | 温湿度检测 | DATA→GPIO2 |
| HC-SR04 | 超声波测距 | TRIG→GPIO9, ECHO→GPIO10 |
| HC-SR501 | 人体红外感应 | OUT→数字口 |
