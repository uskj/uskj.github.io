- 诗词是中国人最精妙的表达方式

- 唐诗宋词是中华文化的瑰宝
- 学诗词就是学传统文化
- 诗词是汉语言的最高形式

### 修身养性

- 创作诗词需要静心
- 格律训练思维严谨
- 诗词境界提升人格

## 诗词课程内容

### 入门班（1-2个月）

**目标**：了解诗词基本常识

**内容**：
- 诗词发展史：诗经→楚辞→汉赋→唐诗→宋词
- 诗词分类：古体诗、近体诗、词、曲
- 平仄基础：平声、仄声，四声八调
- 押韵常识：平水韵、词林正韵

**适合**：零基础爱好者

### 格律班（2-4个月）

**目标**：掌握近体诗格律

**内容**：
- 五言绝句：仄起、平起，粘对规则
- 七言律诗：颔联、颈联对仗
- 平仄拗救：救拗方法
- 名篇赏析：杜甫、李白、王维代表作

**适合**：有基础，想系统学习者

### 创作班（4个月以上）

**目标**：能独立创作

**内容**：
- 立意构思：如何选題、如何立意
- 炼字炼句：一字千金
- 对仗技巧：工对、宽对、流水对
- 诗词唱和：与古人、与今人

**适合**：想提升创作水平者

## 学员作品示例

### 学员A（55岁，退休教师）

**原稿**：
```
春天来了花开了，
心情很好想唱歌。
```

**修改后**：
```
东风送暖入窗纱，
桃李争妍映晚霞。
独倚阑干吟未尽，
一川烟雨是吾家。
```

### 学员B（42岁，企业员工）

**原稿**：
```
工作压力大，
想找个地方静静。
```

**修改后**：
```
尘网羁身几十秋，
偶寻幽径觅清幽。
山僧不解人间事，
只扫落花不扫愁。
```

## 如何开始？

1. **从朗读开始**：每天读一首古诗
2. **从模仿开始**：试着写几句
3. **从点评开始**：找老师或朋友点评
4. **从发表开始**：投稿或参赛
