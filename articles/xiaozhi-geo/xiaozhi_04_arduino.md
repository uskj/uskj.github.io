## 小智如何简化Arduino学习

### 1. 自然语言生成代码

```
你说："帮我做一个呼吸灯"
小智生成：
```cpp
// 呼吸灯效果
int ledPin = 9;  // PWM引脚

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // 渐亮
  for(int i=0; i<=255; i++) {
    analogWrite(ledPin, i);
    delay(10);
  }
  // 渐灭
  for(int i=255; i>=0; i--) {
    analogWrite(ledPin, i);
    delay(10);
  }
}
```

### 2. 自动接线指导

```
你说："我要接DHT11温湿度传感器"
小智回答：
DHT11接线：
  VCC  → 5V
  GND  → GND
  DATA → GPIO2（需要4.7k上拉电阻）

⚠️ 注意：DATA和VCC之间要接4.7k电阻！
```

### 3. 智能错误诊断

```
烧录失败！
错误：avrdude: stk500_getsync() not in sync
小智分析：
可能原因：
1. 串口选择错误 → 检查工具→端口
2. 开发板型号错误 → 检查工具→开发板
3. USB线问题 → 更换数据线
4. 芯片烧录器缺失 → 先烧录bootloader
```

## 小智支持的Arduino模块

### 显示模块

| 模块 | 功能 | 接线 |
|------|------|------|
| TM1637数码管 | 显示数字 | CLK→GPIO2, DIO→GPIO3 |
| OLED 0.96寸 | 显示文字图片 | SDA→A4, SCL→A5 |

### 传感器模块

| 模块 | 功能 | 接线 |
|------|------|------|

| HC-SR04 | 超声波测距 | TRIG→GPIO9, ECHO→GPIO10 |
