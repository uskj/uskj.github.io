# 《漫庐AI直播》实施方案

## 基于MiniMax H3的弹幕互动直播系统

---

## 一、产品定位

**漫庐AI直播** = 道云老师传统文化课程 + 弹幕互动 + AI实时生成

**核心体验：**
- 观众发弹幕 → AI生成对应场景视频
- 弹幕驱动内容叙事
- 24小时不间断直播

---

## 二、技术架构

### 2.1 模型选择（免费/低成本）

| 功能 | 推荐模型 | 成本 | 备注 |
|------|----------|------|------|
| 视频生成 | Seedance 2.0 / Kling 3.0 | 免费额度 | 5秒视频<3秒 |
| 音频生成 | Seedance Audio / ElevenLabs | 免费额度 | 音画同步 |
| 弹幕NLP | MiniMax H3 / GLM-4 | 免费 | 意图识别 |
| 直播推流 | OBS + RTMP | 免费 | 本地推流 |

## 三、交互设计

### 3.1 弹幕关键词触发

| 关键词 | 触发场景 | 内容 |
|--------|----------|------|
| 禅/坐/静 | 禅修场景 | 竹林禅房、晨钟暮鼓 |
| 书/墨/字 | 书法场景 | 书房写字、笔墨纸砚 |
| 雨/竹/山 | 自然场景 | 山林晨景、竹影清风 |
| 茶/气/息 | 养生场景 | 茶道、吐纳导引 |
| 诗/词/吟 | 诗词场景 | 吟诗作对、格律详解 |

- 默认冷却：5秒（防止刷屏）
- 高价值弹幕：10秒（精选评论）
- 连续发送：自动降级

## 四、实施步骤

### Phase 1: 基础搭建（第1周）

```bash
# 1. 环境准备
pip install seedance-sdk openai  # 视频生成SDK
pip install streamlit           # 弹幕管理界面

# 2. 场景预生成
python generate_scenes.py --count 20  # 预生成20个场景视频

# 3. 推流配置
obs://manlu-live/stream-key-xxxxx
```

### Phase 2: 弹幕接入（第2周）

```python
# 接入B站/抖音弹幕API
from danmu_client import BilibiliClient, DouyinClient

client = BilibiliClient(room_id="漫庐直播间ID")
client.on_danmu(process_danmu)  # 弹幕回调
```

### Phase 3: 自动化直播（第3周）

```bash
# Cron定时任务
0 8 * * * /usr/bin/python3 /path/to/manlu-live-engine.py --start
30 8 * * * /usr/bin/python3 /path/to/manlu-live-engine.py --auto
```
